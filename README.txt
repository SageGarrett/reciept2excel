# Receipt2Excel

レシート画像（またはPDF）をWebアプリにアップロードし、
OCRで読み取った内容をExcel / CSVに出力する個人用ツール。


## 想定規模

- 開発者：1人
- 開発期間：3週間


## 技術スタック

Streamlit（UI・制御）
  ↓
Azure OCR（文字認識）
  ↓
Pythonロジック（データ抽出・整形） 
  ↓
CSV / Excel（データ保存）


## 実装予定の機能

- レシート画像（JPEG / PNG）のアップロード
- PDFの入力（1ページ目のみ処理）
- OCRによる文字認識
- 日付・合計金額・店舗名の抽出
- 商品明細の取得（可能な場合）
- 重複チェックによる二重登録防止
- Excel / CSVへの追記保存
- 出力先フォルダの指定


## 非機能要件（目安）

- 処理時間：レシート1枚あたり10〜20秒以内
- 精度目安：
  - 日付・合計金額：80%以上
  - 店舗名・商品明細：70〜80%


## 注意点・割り切り

- OCRの精度は100%ではない
- 取得できない項目がある場合は警告を表示する
- 完全自動化は目標としない
- 個人利用を前提とする
PDFファイルの場合は、1ページ目のみを画像としてOCR処理する。

一般的なレシートPDFが1ページであることを前提とし、
処理時間および操作性を優先した設計としている。
